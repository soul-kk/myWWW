# Soul KK

[soul-kk.top](https://soul-kk.top) 是刘振科（Soul KK）的个人网站与作品集，用来记录前端开发、个人项目、摄影、运动以及日常思考。

## 正式网址

https://soul-kk.top

## 简介

这是一个以作品与生活为线索的个人网站：首页将博客、项目和兴趣并置呈现；进入具体条目后，可阅读项目介绍、生活记录或博客文章。内容追求简洁、直接，也保留了影像、运动和个人表达所带来的温度。

## 技术栈

- **框架与语言**：Next.js 15、React 19、TypeScript
- **样式系统**：Tailwind CSS v4、原生 CSS
- **动画与交互**：GSAP、CSS `:has()`、Pointer Events
- **内容系统**：Git 管理的 Markdown、gray-matter、unified / remark-parse、react-markdown、remark-gfm、Shiki
- **构建与部署**：Next.js 静态导出、GitHub Actions、Nginx

网站使用 `output: "export"` 构建为静态文件。博客文章在构建时解析并生成静态页面，不依赖运行时数据库或 CMS。

## 设计理念

- **黑白与留白**：以 `#111111` 和 `#FFFFFF` 为核心，减少装饰，将注意力留给文字、内容和图片。
- **排版优先**：首页采用大字号标题与清晰的信息层级；Neue Haas Grotesk Text 用于首页主标题，形成更具编辑感的阅读节奏。
- **内容即导航**：首页的标题既是导航入口，也是交互对象；在真实鼠标悬停设备上，作品与生活条目会展开对应的视觉 Scene。
- **同一体验，多种输入**：桌面端保留 hover 场景与动效；触摸设备保持相同的信息布局，但点击会直接进入页面，避免“第一次点击只触发 hover”。
- **响应式而非缩放式**：从桌面双列结构过渡到移动端单列阅读，让不同尺寸下的留白、字号和内容密度保持自然。

| ----------- | ------------------------------------------------------------------------------ | ------------------------------------------------------------------- |

| 博客列表    | `/blog/`                                                                       | 按“技术、生活、其他”筛选 Git 管理的 Markdown 文章。                 |
| 博客详情    | `/blog/[slug]/`                                                                | 构建时生成的文章页面，支持 GFM、代码高亮、Obsidian Callout 与图片。 |
| Work 项目页 | `/frameSpace/`、`/photoAgent/`、`/reserveScript/`、`/omnifood/`、`/wildOasis/` | 展示个人完成或参与的 Web 项目、设计思路与相关链接。                 |
| Life 记录页 | `/badminton/`、`/cycling/`、`/photography/`、`/musicMovies/`                   | 羽毛球、骑行、摄影、音乐与电影等个人兴趣内容。                      |
| 共享页脚    | 全站                                                                           | 联系方式、友链与随滚动切换的黑白视觉状态。                          |
